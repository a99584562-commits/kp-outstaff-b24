# КП · Внедрение Битрикс24 для аутстаффинга

One-pager КП (один `index.html`, без сборки). Открывается двойным кликом, кнопка «Скачать PDF» вызывает печать.

**White-label**: имя клиента не проставлено. Чтобы подставить — заменить в трёх местах:
- `<title>` и `<meta name="description">`
- `.nav-meta` в шапке
- `.foot .rt` в футере

## Проверка печатной вёрстки

Глазами в браузере печать не проверяется — только рендером:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --no-pdf-header-footer --print-to-pdf=out.pdf "file:///Users/artemskobelev/Claude Code/kp-outstaff-b24/index.html"
```

Сейчас 13 страниц A4, пустых нет. Что важно в `@media print`:
- `.est-shell,.est-core{break-inside:auto}` + `.erow{break-inside:avoid}` — иначе смета не влезает целиком и оставляет пустую страницу под заголовком;
- на A4 ширина ≈794px, поэтому срабатывают мобильные медиа-запросы — колонки (`.contours`, `.intg`, `.reps`, `.plan`, `.results`, `.auto`, `.stage-core`) возвращаются принудительно в print-блоке, иначе всё вытягивается в столбик на 20+ страниц;
- `#smeta{page-break-before:always}` — смета всегда с новой страницы, перед ней стоит блок «Как идёт проект», который добирает остаток предыдущей.
